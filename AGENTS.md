
# AGENTS.md — Rain Ripple Key Generator

## 1. Project Overview

Rain Ripple Key Generator is a research project integrating computer
vision, embedded hardware, and software to investigate the generation
of experimental key material from captured rain ripple images.

The pipeline analyzes isolated ripple images, extracts measurable
characteristics, and uses those characteristics as inputs to a
deterministic mathematical transformation involving a Runge–Kutta
integration method and bitmap scrambling.

The system includes desktop, embedded, server, mobile, and web
components.

### Primary Objectives
- Generate experimental 32–64-bit outputs from isolated ripple images.
- Evaluate output sequences using appropriate statistical tests.
- Document the complete methodology, limitations, and results.
- Maintain a reproducible and resource-efficient implementation.
- Keep all platform interfaces consistent and testable.

### Security Boundaries
- Statistical randomness is not equivalent to cryptographic security.
- Never claim that passing NIST SP 800-22 proves secure key generation.
- Evaluate the entropy source and min-entropy assumptions separately.
- Document determinism, input dependence, possible bias, and attack surfaces.
- Treat 32–64-bit outputs as experimental research artifacts, not
  production encryption keys.
- Production encryption must use established cryptographic libraries,
  approved algorithms, and appropriately sized keys generated by a CSPRNG.
- Never invent cryptographic algorithms or replace standard primitives
  with custom scrambling or chaotic-system implementations.
